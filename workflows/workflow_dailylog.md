# workflow_dailylog.md — 프로젝트 일일 기록

CLAUDE.md 의 라우팅에서 "일일 기록 / 진행도 정리" 요청 시 로드되는 2층 파일이다.
상세 실행 규칙은 project-daily-log 스킬의 SKILL.md 와 동일하게 유지한다.

## 실행 단계 (번호 순서, 누락 금지)
1) ./templates/daily_log_template.md 를 반드시 읽는다
2) 메타데이터 확보 — project, date(기본 오늘), author, status
3) 사용자가 적은 작업 내용을 항목 단위로 끊어 체크리스트로 재구성
4) 오늘 한 일 / 이슈·블로커 / 내일 할 일 로 분류
5) YAML 머리말 + 본문 구조에 맞춰 작성
6) ./[기록루트]/[project_id]/[YYYY-MM-DD].md 로 반드시 저장
7) 저장 경로를 사용자에게 알림

## 금지사항
- 이모지, 볼드체·마침표 남발 금지
- "~하는 것이 중요합니다" 류 군더더기 금지
- 확신의 톤 금지 (입력에 없는 사실 추정 금지)
- status 는 정상/지연/이슈 중 하나만
- progress 는 숫자만 (% 기호 금지)

## 분량
- 각 항목 1~2줄, 불릿 위주
- 작업 단위로 분리
