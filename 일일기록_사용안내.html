프로젝트 일일 기록 안내

매일의 작업을 자유롭게 적으면 AI가 표준 체크리스트로 정리해 저장합니다. 아래 4단계를 눌러 입력 예시와 출력 양식이 어떤 모습인지 확인하세요. 처음 쓰는 분도 이 순서만 따르면 됩니다.

세 가지 사용 경로

  1. 웹(가장 쉬움) — claude.ai 에서 그날 한 작업을 적고 "일일 기록 정리해줘" 요청
  2. Claude Code — 레포 폴더에서 claude 실행 → "오늘 작업 일일 기록으로 정리해줘"
  3. UI 앱 — streamlit run scripts/app.py → 프로젝트·날짜 선택 + 작업 내용 입력 → 프롬프트 자동 생성 → 복사해서 Claude 에 붙여넣기
Git 공유 규칙 — clone 하면 공통 기능(SKILL·워크플로우·앱)은 함께 받지만, output/ 의 생성된 일일 기록과 uploads/ 의 업로드 파일은 .gitignore 로 제외되어 올라가지 않습니다. 각자 로컬에만 쌓입니다.
